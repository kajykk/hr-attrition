## 4. 验收流程

### 4.1 验收阶段

| 阶段 | 时间 | 内容 | 参与 |
|---|---|---|---|
| 初验 | 2026-09-15 | 功能 + 性能自验 | 邝振华 |
| 正式验收 | 2026-09-18 | 全量验收 | 邝振华 + 试点 + 法律 |
| 终验 | 2026-09-21 | 验收会议 + 签署 | 全体 |

### 4.2 验收会议议程

1. 项目总结（10min）
2. 功能演示（30min）
3. 性能/安全/合规报告（20min）
4. 试点客户反馈（15min）
5. 验收标准逐项确认（30min）
6. Q&A（15min）
7. 验收结论签署（10min）

### 4.3 验收决策机制

- 全部验收 ID 通过 → **通过验收**
- 1-3 项非关键不通过 → **有条件通过**（30 天内整改）
- 关键项（F/M/S/C）不通过 → **不通过验收**

### 4.4 验收参与方

| 角色 | 职责 |
|---|---|
| 项目负责人 | 提交验收材料 + 演示 |
| 试点客户代表 | 试点反馈 + 签署 |
| 法律顾问 | 合规验收 |
| 伦理委员会 | 公平性验收 |
| 邀请专家（可选）| 独立评审 |
