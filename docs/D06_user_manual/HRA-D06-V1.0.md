## 1. 快速入门

### 1.1 系统访问

- 访问地址：`https://hra.example.com`
- 推荐浏览器：Chrome 110+ / Edge 110+ / Safari 16+
- 移动端：响应式 Web，暂不提供原生 App

### 1.2 首次登录

1. 收到管理员邀请邮件，点击「激活账号」链接
2. 设置密码（长度 ≥ 12，含大小写+数字+特殊字符）
3. 可选：绑定 2FA（管理员强制开启）
4. 完成激活，跳转登录页

### 1.3 角色切换

单账号仅属于一个角色。如需切换角色，请联系管理员开通新账号。

## 2. 功能模块操作指引

### 2.1 HRBP 操作

#### 2.1.1 查看预警列表

**前置条件**：已登录 HRBP 账号

**操作步骤**：
1. 左侧菜单点击「预警中心」
2. 默认展示「待我处理」标签页
3. 可切换标签：「全部」「待确认」「处理中」「待复核」「已关闭」
4. 顶部筛选：等级（P0/P1/P2）/部门/时间范围
5. 点击预警卡片进入详情

**结果说明**：预警卡片显示员工姓名（脱敏）/部门/等级/风险分/创建时间

**常见问题**：
- Q：为何看不到某员工的预警？
  A：仅显示分配给你的预警，未分配的需 HR 经理重新分配
- Q：预警数量过多如何处理？
  A：按等级排序，先处理 P0

#### 2.1.2 确认预警

1. 进入预警详情页
2. 点击「确认」按钮
3. 在弹窗填写确认备注（如：已联系员工面谈）
4. 点击「确认提交」
5. 状态变为「处理中」

#### 2.1.3 执行干预

1. 在预警详情页点击「记录干预」
2. 选择干预类型：调薪 / 转岗 / 培训 / 辅导 / 其他
3. 填写干预内容描述
4. 点击「保存」
5. 系统自动进入「待复核」状态

#### 2.1.4 申诉预测结果（人在回路）

当 HRBP 认为预测不准确时：

1. 在预警详情页点击「申诉」按钮
2. 选择申诉理由：
   - 误报（员工无离职意向）
   - 信息过时（员工状态已变化）
   - 不准确（归因错误）
   - 误导（可能导致不当干预）
3. 填写详细描述
4. 点击「提交申诉」
5. 申诉进入审核队列（HR 经理审核）

#### 2.1.5 标记预测准确性

1. 在预警详情页点击「标记准确性」
2. 选择：完全准确 / 部分准确 / 不准确 / 误导
3. 填写备注
4. 点击「保存」
5. 标记数据累积 100 条后触发模型再训练评估

#### 2.1.6 生成 LLM 保留建议

1. 在预警详情页点击「生成保留建议」
2. 选择建议类型（可多选）：调薪 / 转岗 / 培训 / 辅导
3. 点击「生成」
4. 等待流式响应（首字 < 2s，全部生成约 5-10s）
5. 建议生成完成后可：复制 / 编辑 / 执行

### 2.2 HR 经理操作

#### 2.2.1 查看部门风险画像

1. 左侧菜单点击「部门画像」
2. 选择部门（默认全公司）
3. 查看以下信息：
   - 风险分布饼图（5 档等级）
   - Top10 高风险员工列表
   - 趋势曲线（周/月/季）
   - 部门对比柱状图

**注意**：仅 HR 经理 + 管理员可见具体员工姓名，直线经理仅看团队概览

#### 2.2.2 复核预警

1. 进入「待复核」预警详情
2. 查看 HRBP 干预记录
3. 点击「复核通过」或「复核驳回」
4. 填写复核意见
5. 通过后状态变为「已关闭」

#### 2.2.3 审核申诉

1. 左侧菜单点击「申诉审核」
2. 查看申诉详情（含原预测/SHAP/HRBP 备注）
3. 点击「批准」或「驳回」
4. 批准后预警自动关闭

#### 2.2.4 导出报表

1. 左侧菜单点击「报表中心」
2. 选择报表类型：
   - 部门风险画像
   - 趋势分析
   - 干预效果
3. 设置筛选条件（时间范围/部门）
4. 选择格式（PDF/Excel）
5. 点击「导出」
6. 异步生成完成后邮件通知 + 站内下载链接

### 2.3 直线经理操作

#### 2.3.1 查看团队风险概览

**注意**：直线经理仅能查看本团队概览，不能查看具体员工风险分

1. 左侧菜单点击「团队画像」
2. 查看团队整体风险分布
3. 查看团队趋势
4. 如有高风险员工，可点击「请求 HR 支持」

### 2.4 管理员操作

#### 2.4.1 用户与租户管理

1. 「系统管理」→「用户管理」
2. 邀请新用户（邮箱 + 角色 + 部门）
3. 禁用/启用用户
4. 重置密码

#### 2.4.2 模型治理

1. 「系统管理」→「模型治理」
2. 查看模型版本列表
3. 启动金丝雀发布（5% → 25% → 100%）
4. 监控漂移告警
5. 查看公平性报告

#### 2.4.3 激活 Kill Switch

**仅紧急情况使用**：

1. 「系统管理」→「Kill Switch」
2. 输入激活原因
3. 点击「激活」
4. 全部预测服务暂停，已生成预警保持
5. 通知所有 HR 用户

#### 2.4.4 审计日志查询

1. 「系统管理」→「审计日志」
2. 按用户/操作/资源/时间筛选
3. 导出日志（CSV）

### 2.5 员工操作（数据权利）

#### 2.5.1 行使数据权利

1. 访问 `https://hra.example.com/employee-portal`
2. 输入工号 + 身份证后 6 位验证
3. 选择请求类型：
   - 查询：查看个人预测记录
   - 导出：下载全部个人数据
   - 删除：申请删除个人数据
   - 更正：申请修正错误信息
4. 提交请求
5. 系统在 30 天内处理完成，邮件通知结果

## 4. 常见问题（FAQ）

### 4.1 登录相关

**Q1：忘记密码怎么办？**
A：登录页点击「忘记密码」，输入注册邮箱，按邮件链接重置（30 分钟有效）。

**Q2：账号被锁定如何处理？**
A：连续 5 次密码错误自动锁定 30 分钟。如急需解锁，联系管理员。

**Q3：2FA 丢失如何处理？**
A：联系管理员重置 2FA，重新绑定。

### 4.2 数据相关

**Q4：为何员工列表看不到某些员工？**
A：检查筛选条件（部门/状态）。离职员工默认隐藏，可在筛选中开启。

**Q5：批量导入失败怎么办？**
A：下载错误报告查看具体行/字段问题，修正后重新导入。

**Q6：员工数据更新后多久影响预测？**
A：实时更新影响下次预测（每日 02:00 全量重算），可手动触发单员工预测。

### 4.3 预警相关

**Q7：为何某员工风险分很高却没有预警？**
A：可能原因：①7 天内已有预警（去重）；②夜间生成（22:00-08:00 仅入库不推送）；③Kill Switch 激活。

**Q8：预警可以撤回吗？**
A：已确认的预警无法撤回，但可以申诉后由 HR 经理关闭。

**Q9：如何调整预警阈值？**
A：联系管理员，在「系统设置」中调整 P0/P1/P2 阈值。

### 4.4 LLM 建议相关

**Q10：LLM 建议生成失败？**
A：可能原因：①LLM 服务不可用；②限流（10 次/分钟）。失败后系统返回规则模板建议。

**Q11：LLM 建议不准确怎么办？**
A：可编辑后保存，或标记为「不准确」，反馈数据用于改进 Prompt。

### 4.5 合规相关

**Q12：员工撤回同意后会发生什么？**
A：立即停止该员工预测；已有预测记录保留 30 天后删除；预警保持已关闭状态。

**Q13：员工申请删除数据如何处理？**
A：30 天内完成：软删除 → 备份移除 → 审计日志保留（不含 PII）。

## 5. 错误提示与处理

| 错误提示 | 原因 | 用户处理 |
|---|---|---|
| 「邮箱格式不正确」| 输入不符合邮箱规范 | 检查邮箱格式 |
| 「账号或密码错误」| 密码错误 | 重置密码或重试 |
| 「账号已禁用」| 管理员禁用 | 联系管理员 |
| 「权限不足」| 角色不匹配 | 联系管理员调整角色 |
| 「资源不存在」| ID 错误或跨租户 | 检查 URL 或联系管理员 |
| 「操作过于频繁」| 触发限流 | 等待 1 分钟后重试 |
| 「服务暂时不可用」| Kill Switch 激活 | 等待管理员恢复 |
| 「LLM 调用失败」| OpenAI 服务异常 | 重试或使用规则建议 |
| 「批量导入失败：第 N 行」| 数据格式错误 | 修正后重新导入 |
| 「文件大小超限」| 超过 10MB | 拆分文件 |

## 6. 最佳实践

### 6.1 高风险员工处理 SOP

1. **接警**：收到 P0 预警后 4 小时内确认
2. **分析**：查看 SHAP Top3 归因
3. **建议**：生成 LLM 保留建议
4. **干预**：48 小时内执行干预
5. **回访**：30 天后回访员工状态
6. **闭环**：60 天后关闭预警并标记准确性

### 6.2 团队稳定性提升

1. HR 经理每周查看部门画像
2. 关注 Top10 高风险员工
3. 月度生成趋势报表
4. 季度复盘干预效果
5. 调整 HRBP 工作量分配

### 6.3 合规操作要点

1. 员工首次入职即签署同意书
2. 离职时主动告知数据保留与删除政策
3. 不在邮件/IM 中明文讨论员工风险分
4. LLM 建议生成后 HR 复核再执行
5. 定期参加伦理委员会培训
