# 第一部分：测试计划

## 1. 测试策略

### 1.1 测试目标

- 验证 HRA 系统功能、性能、安全、合规满足 SRS 要求
- 提供 80%+ 代码覆盖率证据
- 通过 6 层测试金字塔：单元 / 集成 / 契约 / E2E / 性能 / 安全

### 1.2 测试范围

**在范围**：
- 后端 API（30+ 端点）
- 前端 7 个核心页面（登录/员工管理/风险SHAP/预警中心/LLM建议/部门画像/模型治理审计）
- ML 模型（4 模态）
- 异步任务（Celery）
- 多租户隔离
- 安全（认证/授权/加密/限流）
- 合规（PIPL/公平性）

**不在范围**：
- 基础设施（云厂商负责）
- 第三方系统（HR 系统/OKR 系统）
- LLM 模型本身（仅测试调用与降级）

### 1.3 测试金字塔

```
       ┌─────┐
       │ E2E │  ~50 用例
       └──┬──┘
       ┌──┴──┐
       │ 契约 │  ~150 用例
       └──┬──┘
       ┌──┴──┐
       │ 集成 │  ~300 用例
       └──┬──┘
       ┌──┴──┐
       │ 单元 │  ~1000 用例
       └─────┘
```
